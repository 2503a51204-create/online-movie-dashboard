# CineVerse Pro

Frontend: HTML/CSS/JavaScript. Backend: Python Flask + Pandas. Data: Excel. BI: Power BI.

Run:
1. Open terminal in `backend`.
2. `pip install -r requirements.txt`
3. `python server.py`
4. Open `http://127.0.0.1:5000`

The frontend is responsive, keyboard-friendly, has skip navigation, visible focus, light/dark theme, search, filters, separate chart sections and helpful empty states. The Excel workbook is shared by Python and Power BI.
